# Автопрокат жүйесі

Автор: Кенжебай Аслан

## Мәселе
Автопрокат компаниясында көліктерді жалға беру қолмен, қағазда немесе кестеде жүргізіледі: бос көлікті табу ұзаққа созылады, брондаулар қайталанып қалады. Жүйе клиентке көлікті онлайн таңдап, брондап, төлеуге мүмкіндік береді, ал менеджерге көліктер мен брондауларды бір жерден басқаруға көмектеседі.

## Талаптар
### Функционалдық
1. Жүйе клиентке бос көліктер тізімін көрсетуі керек
2. Жүйе таңдалған мерзімге көліктің бос екенін тексеруі керек
3. Жүйе жалдау бағасын есептеуі керек
4. Жүйе брондауды сақтап, клиентке растау жіберуі керек
